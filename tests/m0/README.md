本目录只冻结已确认正确的算法和输出行为，不修复 M1 的 NaN/Inf、数量整数契约、注册生成器最终验证、搜索异常分类或 Pareto 非有限值问题。

```powershell
python -m pytest -ra -x
```

`-x` 让首次失败立即停止。搜索 fixture 还会在导出前核对 `415 / 18`；不匹配时应调查并报告，不能修改生产代码迎合计数。

## 唯一静态 fixture

`fixtures/reference.json` 保存 9 × 24 = 216 个点、每方案 18 项几何结果、比较参数、每 N 搜索数量与 18 个 Pareto ID。四基准是九方案的子集，共用一份坐标，无重复快照。未复制图片、415 份候选坐标或完整批量搜索表。

来源为 M0 开始时的提交 `3da5ef8` 和用户提供的上一轮审计结论。JSON 记录来源文件及其 SHA-256，方便追溯；测试不依赖可被脚本覆盖的 `outputs/` 文件。

- A、B、E 坐标取自仓库已保存并经上一轮审计复核的三个代表性 CSV，再逐点与下列独立数学构造核对。
- C、D、F、G、H、I 没有已保存的完整坐标文件，按下列固定数学构造计算并冻结；不使用待测生成器制备期望值。
- 九方案指标和比较参数取自已审计的 `outputs/summaries/layout_comparison.csv`。全部指标又用 `math.dist`、`math.hypot`、`statistics.mean/pstdev` 及独立反射检查复核。
- 旧 `layout_summary.csv` 的 12 列契约逐列写入测试；四行数值与已审计基准指标对应，保留 `mean_nearest_neighbour_mm` 等旧拼写以及 D 的对称性结果。
- 各 N 合法数量取自已审计的 `variable_n_results.csv`，Pareto ID 取自 `pareto_candidates.csv`；415/18 也在制备 fixture 前通过完整默认搜索再次确认。426 来自上一轮审计，并在本轮复跑规格构造时确认。

测试运行时只读取 JSON，不重写或更新 fixture，也不调用待测生成器生成期望值。`test_reference_data.py` 的数学核对函数只使用固定案例公式和标准数学运算，不导入 `layouts` 或 `geometry`。

## 坐标与顺序核对依据

所有角度均按逆时针增长，编号从 1 开始，对应数组下标 0。

| 方案 | 独立数学核对与顺序 |
| --- | --- |
| A_Rectangular | x = −45,−27,−9,9,27,45；y = −27,−9,9,27；先逐行、再逐列 |
| B_Hexagonal | 4–5–6–5–4 行；x 为相应奇/偶数倍 8；y = (−2,−1,0,1,2) × 8√3；从下到上、从左到右 |
| C_Double_Ring | 25 mm 的 8 点环，然后 48 mm 的 16 点环；各环从正 x 轴开始 |
| D_Triple_Ring | 原点，然后 25 mm 的 7 点环，再 48 mm 的 16 点环；各环从正 x 轴开始。仅 x 轴反射对称，y 轴及原点对称为 False |
| E_Sector_4x6 | 每扇区依次取半径 18、32、46；每层相对全局的两个起始角为 −π/48、7π/48；四个扇区依次增加 π/2 |
| F_Radial_8x3 | 每条辐条依次半径 16、31、46；角度 π/16 + kπ/4 |
| G_Staggered_Ring_8_16 | C 的环数及半径，外环整体增加 π/16 |
| H_Nonuniform_3_Ring | 18/34/50 mm 各 4/8/12 点，起始角分别 0/π/8/π/12，依次完成每一环 |
| I_Deterministic_Irregular | 第 i 个点满足 r²=2500(2i+1)/48，θ=iπ(3−√5)，i=0..23 |

最近邻均值、总体标准差、CV、均匀性分数、最大/平均半径及径向总体标准差均受到保护，同时核对数量、边界、间距、不重叠、可行性、失败原因列表与三项对称性。

专项幂律测试用三环端点 18、50 mm：指数 1、2、1/2 时中间半径分别是 34、26、18+16√2。还检查缺省指数、整体角偏移叠加各环偏移、中心点前置和单环取内端点。这些期望来自手算值，没有通过 `ring` 生成器反向构造。

## 容差与输出验证

- 坐标按原顺序比较，绝对容差 `1e-9 mm`、相对容差 0；不先排序，也不比较浮点字符串。
- 几何数值采用绝对容差 `1e-9`、相对容差 `1e-12`，允许三角函数和总体统计的浮点末位差异。
- 相位及参数采用约 `1e-12` 容差。整数编号、列名、列序、布尔值和 BOM 按契约精确检查。
- 三个脚本真实调用 CSV 导出、绘图和目录创建，只将输出根目录与 argv 暂时重定向到现有 `outputs/test_tmp/` 下；测试结束恢复模块全局变量。
- 每次全量运行实际生成 4 张基准图、9 张比较图、12 张 Pareto 候选图和 1 张权衡图，共 26 张 PNG。每张检查文件、非空、PNG 签名、正常解码、有效通道和 500–6000 像素范围；没有逐像素比较。
- 在原始 `Figure.savefig` 运行时观察标签与圆形位置，将绘图编号、圆心及 CSV 行位置逐一关联；没有替换绘图实现或取消真实保存。
- 搜索实际生成并逐一检查全部 415 个坐标 CSV，同时检查两个搜索汇总表。

进入 M1 后，如修复造成预期变化，应说明受影响的契约并独立核对期望值，不能批量重录当前生成器的输出来消除失败。
